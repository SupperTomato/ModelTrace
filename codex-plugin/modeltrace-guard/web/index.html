Sampling settings

Work-tool interval (calls)
—

The submission deadline starts when a probe is issued; the default is 180 seconds. Timeout is recorded only as a coverage gap, never a model mismatch. This is not the sampling interval; changes apply to newly issued probes.

Probe language English only

Triggered by work-tool calls; equal bounds fix the interval. There are no per-turn or task-total limits. Notify on the first mismatch, then run retries (default 3 extra retries, excluding the initial check). If every retry still mismatches, require the agent to stop the original task and notify the user. The current batch retains its original retry count and language; updates preserve history.
